# 햄찌캡처 (Windows)

**한국어** | [English](README.en.md)

실행 시 Windows 표시 언어를 따라 한국어/영어로 시작하며, ⓘ 정보 창에서 언제든 전환할 수 있습니다.

## 실행
1. Python 3.9+ 설치 (python.org, "Add to PATH" 체크)
2. `pip install -r requirements.txt`
3. `python app.py`

## exe로 만들기
zip을 **먼저 압축 해제**한 뒤 `build.bat` 더블클릭 → `dist\HamzziCapture.exe` (햄스터 아이콘 포함)

## 사용법
| 기능 | 단축키 |
|---|---|
| 영역 캡처 (모니터마다 오버레이, 한 모니터 안에서 드래그) | Ctrl+Shift+A |
| 현재 모니터(마우스 위치) | Ctrl+Shift+M |
| 모든 모니터 한 장으로 | Ctrl+Shift+F |
| 활성 창 | Ctrl+Shift+W |

햄찌캡처 창 자체(메인·편집기·정보 창)를 캡처하려면, 그 창을 클릭해 활성화한 상태에서 **Ctrl+Shift+W**를 누르세요. (창 위의 버튼으로는 캡처 전에 창이 숨겨져서 자기 자신을 찍을 수 없습니다.)

캡처하면 메인 창에 미리보기만 표시됩니다. **✏ 편집** 버튼을 눌러야 편집기가 열리고, 메인 창에서 바로 📋 복사 / 💾 저장도 가능합니다.

최근 캡처 5개는 미리보기 아래 썸네일로 보관되며, 클릭하면 그 캡처를 다시 열어 편집/복사/저장할 수 있습니다. 각 썸네일 오른쪽 위의 **×** 버튼을 누르면 그 캡처가 삭제됩니다. (프로그램을 끄면 사라집니다. 6번째부터는 가장 오래된 것이 밀려납니다.)

편집기: 펜 / 형광펜 / 선 / 화살표 / 사각형 / 원 / 텍스트 / 모자이크, Ctrl+Z 취소, Ctrl+C 클립보드 복사, Ctrl+S 저장.

같은 프로그램을 두 번 실행하면 단축키가 충돌하므로, 이미 켜져 있으면 안내 후 종료됩니다.

## 언어 / 글꼴
- 실행할 때 Windows 표시 언어가 한국어면 한국어, 그 외에는 영어로 시작합니다.
- ⓘ 정보 창의 **언어** 버튼(한국어 | English)으로 언제든 바꿀 수 있고, 즉시 화면에 반영됩니다. 선택한 언어는 저장하지 않으므로 다음 실행 때 다시 자동으로 정해집니다.
- 두 언어 모두 Windows 기본 글꼴인 **맑은 고딕**을 사용해 글꼴이 달라 보이지 않습니다. 별도로 글꼴을 설치할 필요가 없습니다.

## 보안 · 개인정보
**프로그램이 하는 일 / 하지 않는 일**
- 인터넷 통신을 전혀 하지 않습니다. 캡처한 내용은 이 PC 밖으로 나가지 않습니다.
- 다른 프로그램을 실행하거나 레지스트리·시작 프로그램을 건드리지 않습니다.
- 파일은 사용자가 "저장"으로 고른 위치에만 저장되며, PNG/JPG만 지원합니다.
- 전역 단축키는 Windows 단축키 등록 방식이며 Ctrl+Shift+A/M/F/W 네 개에만 반응합니다(키 입력 전체를 읽지 않습니다).

**사용 시 주의**
- 최근 캡처 5개는 프로그램을 끌 때까지 메모리에 남습니다. 비밀번호·개인정보가 찍힌 화면은 사용 후 프로그램을 종료하세요.
- "복사"한 이미지는 다른 것을 복사하기 전까지 클립보드에 남고, Windows 클립보드 기록(Win+V)에도 남을 수 있습니다.

**exe 파일을 받았다면**
- 코드 서명이 없어서 Windows SmartScreen 경고가 뜨거나 일부 백신이 오탐할 수 있습니다. 가장 안전한 방법은 소스를 받아 직접 `build.bat`으로 빌드하는 것입니다.
- 취약점이나 문제를 발견하면 GitHub 저장소의 Issues에 남겨 주세요.
