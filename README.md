# 햄찌캡처 (Windows)

**한국어** | [English](README.en.md)

Windows용 화면 캡처 프로그램입니다. 한국어와 영어를 지원합니다.

<img width="801" height="510" alt="Hamzzicapture02" src="https://github.com/user-attachments/assets/4f5f4790-2f38-4080-9294-d4d4fa96a334" />



## 실행
1. Python 3.9+ 설치 (python.org, "Add to PATH" 체크)
2. `pip install -r requirements.txt`
3. `python app.py`

## exe로 만들기
zip을 **먼저 압축 해제**한 뒤 `build.bat` 더블클릭 → `dist\HamzziCapture.exe` (햄스터 아이콘 포함)

## 사용법
| 기능 | 단축키 |
|---|---|
| 영역 캡처 (모니터마다 오버레이, 한 모니터 안에서 드래그) | Ctrl+Shift+A |
| 현재 모니터(마우스 위치) | Ctrl+Shift+M |
| 모든 모니터 한 장으로 | Ctrl+Shift+F |
| 활성 창 | Ctrl+Shift+W |

- 캡처하면 메인 창에 미리보기가 뜹니다. **편집**을 눌러야 편집기가 열리고, **복사**와 **저장**은 메인 창에서 바로 할 수 있습니다.
- 최근 캡처 5개는 미리보기 아래 썸네일로 남고, 눌러서 다시 열 수 있습니다. 썸네일의 **×** 는 하나, **모두 지우기**는 전부(확인 후) 지웁니다. 프로그램을 끄면 사라지고, 6번째부터는 오래된 것부터 밀려납니다.
- 메인 창 단축키: **Ctrl+C** 복사, **Ctrl+S** 저장, **Ctrl+V** 클립보드의 이미지(복사한 이미지 파일 포함)를 새 캡처로 불러오기. 한글 입력 상태에서도 됩니다.
- 헤더의 **⚙ 설정**: 저장 폴더를 정하고, 캡처 직후 클립보드 복사 / 저장 폴더에 PNG 저장을 자동으로 할지 고릅니다. 저장 버튼의 파일 선택 창도 이 폴더에서 시작합니다.
- 편집기: 펜 / 형광펜 / 선 / 화살표 / 사각형 / 원 / 텍스트 / 모자이크 / **자르기**. Ctrl+Z 취소, Ctrl+C 복사, Ctrl+S 저장. 자르기는 남길 영역을 드래그하면 바로 적용되고, 취소로 되돌립니다.
- 모자이크는 칸 크기가 최소 12px이고 칸마다 밝기를 조금씩 무작위로 바꿔서 원래 글자를 되살리기 어렵게 했습니다. 그래도 비밀번호처럼 꼭 가려야 하는 정보는 **펜을 굵게 해서 빈틈없이 덧칠하거나 캡처 범위에서 빼는 것**이 가장 안전합니다.
- 프로그램을 두 번 실행하면 단축키가 겹치므로, 이미 켜져 있으면 안내만 하고 종료됩니다.

## 보안 · 개인정보
**데이터 처리**
- 인터넷에 연결하지 않습니다. 캡처한 내용은 이 PC 밖으로 나가지 않습니다.
- 다른 프로그램을 실행하지 않고, 레지스트리와 시작 프로그램도 건드리지 않습니다.
- 이미지는 "저장"으로 고른 위치에 저장합니다(PNG/JPG). **자동 저장을 켠 경우**, 설정한 저장 폴더에 저장합니다.
- 이미지 말고 쓰는 파일은 설정 파일(`%APPDATA%\HamzziCapture\settings.json`) 하나뿐이고, 언어·저장 폴더·자동 복사/저장 여부가 들어 있습니다.
- 전역 단축키는 Windows의 단축키 등록 기능으로 Ctrl+Shift+A/M/F/W 네 개만 받습니다. 키 입력을 전부 읽지는 않습니다.

**사용 시 주의**
- 최근 캡처 5개는 프로그램을 끌 때까지 메모리에 남습니다. 비밀번호·개인정보가 찍힌 화면은 사용 후 **모두 지우기**를 누르거나 프로그램을 종료하세요.
- "복사"한 이미지는 다른 것을 복사하기 전까지 클립보드에 남고, Windows 클립보드 기록(Win+V)에도 남을 수 있습니다.

**exe 파일을 받았다면**
- 코드 서명이 없어서 Windows SmartScreen 경고가 뜨거나 일부 백신이 오탐할 수 있습니다. 가장 안전한 방법은 소스를 받아 직접 `build.bat`으로 빌드하는 것입니다.
- 취약점이나 문제를 발견하면 GitHub 저장소의 Issues에 남겨 주세요.
